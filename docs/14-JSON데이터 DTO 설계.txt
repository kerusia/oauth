[질문] 카카오 프로필 연계 시 JSON 데이터에 대해 어떤 식으로 DTO를 설계해야할까?

[확인]
API연계되는 데이터는 생성자를 통해 한번만 설정하고 그 후로는 읽기 전용이라고 생각하면 된다.
이러한 객체를 불변(Immutable) 객체라 부르고 데이터 객체를 만드는 record 문법을 사용하면 된다.

JSON 내 KEY 값이 기본 자료형이면 거기에 맞는 자료형으로 정의하고, Map인 경우 record 객체로 작성하면 된다.

@JsonNaming(PropertyNamingStrategies.SnakeCaseStrategy.class)
@JsonIgnoreProperties(ignoreUnknown = true)
public record KakaoUserInfoResponse(
    Long id,
    KakaoProperties properties,
    KaKaoAccount kakaoAccount
) {
}

@JsonNaming(PropertyNamingStrategies.SnakeCaseStrategy.class)
@JsonIgnoreProperties(ignoreUnknown = true)
public record KakaoProperties(
    String nickname,
    String profileImage,
    String thumbnailImage
) {
}

@JsonNaming(PropertyNamingStrategies.SnakeCaseStrategy.class)
@JsonIgnoreProperties(ignoreUnknown = true)
public record KakaoAccount(
    KakaoProfile profile,
    boolean isEmailVerified,
    String email
) {
}

@JsonNaming(PropertyNamingStrategies.SnakeCaseStrategy.class)
@JsonIgnoreProperties(ignoreUnknown = true)
public record KakaoProfile(
    String nickname,
    String profileImageUrl
) {
}
