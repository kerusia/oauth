1. 구글, 카카오, 네이버 개발자 센터 어플리케이션에서 서버용 리다이렉션 URI 등록
    Redirect URL도 정해진 룰이 있는건가?
        http://localhost:8080/login/oauth2/code/google
        http://localhost:8080/login/oauth2/code/naver
        http://localhost:8080/login/oauth2/code/kakao

2. oauth2-client 의존성 추가

    [libs.versions.toml]
        [libraries]

        # Spring Boot
        spring-boot-oauth2-client = { module = "org.springframework.boot:spring-boot-starter-oauth2-client" }


    [build.gradle]
        dependencies {
            implementation libs.spring.boot.oauth2.client
        }

3. application.yml 환경설정

    spring:
      security:
        oauth2:
          client:
            registration:
              google:
                client-id: ${GOOGLE_CLIENT_ID}
                client-secret: ${GOOGLE_CLIENT_SECRET}
                scope: "openid, email, profile"
                redirect-uri: http://localhost:8080/oauth/code/google
                authorization-grant-type: "authorization_code"
              kakao:
                client-id: ${KAKAO_CLIENT_ID}
                client-secret: ${KAKAO_CLIENT_SECRET}
                scope: "openid, email, profile"
                redirect-uri: http://localhost:8080/oauth/code/kakao
                authorization-grant-type: "authorization_code"
              naver:
                client-id: ${NAVER_CLIENT_ID}
                client-secret: ${NAVER_CLIENT_SECRET}
                scope: ""
                redirect-uri: http://localhost:8080/oauth/code/naver
                authorization-grant-type: "authorization_code"
            provider:
              google:
                authorization-uri: https://accounts.google.com/o/oauth2/v2/auth
                token-uri: https://oauth2.googleapis.com/token
                user-info-uri: https://openidconnect.googleapis.com/v1/userinfo
                user-name-attribute: sub
              kakao:
                authorization-uri: https://kauth.kakao.com/oauth/authorize
                token-uri: https://kauth.kakao.com/oauth/token
                user-info-uri: https://kapi.kakao.com/v2/user/me
                user-name-attribute: id
              naver:
                authorization-uri: https://nid.naver.com/oauth2.0/authorize
                token-uri: https://nid.naver.com/oauth2.0/token
                user-info-uri: https://openapi.naver.com/v1/nid/me
                user-name-attribute: sub

5. 클라이언트 서버 로그인 구현
    OAuth2AuthorizationRequestRedirectFilter 클래스를 보면
    "http://도메인/oauth2/authorization/[registrationId]"으로 고정되어 있음

    [클라이언트 소스]
        serverGoogleAuthUri: "http://localhost:8080/oauth2/authorization/google"
        serverKakaoAuthUri: "http://localhost:8080/oauth2/authorization/kakao"
        serverNaverAuthUri: "http://localhost:8080/oauth2/authorization/naver"

        serverGoogleLogin() {
            const authUri = `${this.serverGoogleAuthUri}`;
            window.location.href = authUri;
        },
        serverKakaoLogin() {
            const authUri = `${this.serverKakaoAuthUri}`;
            window.location.href = authUri;
        },
        serverNaverLogin() {
            const authUri = `${this.serverNaverAuthUri}`;
            window.location.href = authUri;
        }
